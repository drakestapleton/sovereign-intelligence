How the counts work

A pull is one fetch this seed served: a git clone or git fetch over HTTPS, counted from the web server's log, or a rad clone or rad sync over the Radicle network, counted from the node's log. Each project page shows the last 14 days, with distinct hosts and distinct Radicle peers per day. Only counts are kept: tools/tally.om reads the logs on this machine and writes numbers, never an address. Seeding nodes are the Radicle nodes this seed knows to be copying the project, itself included. Machine-readable: stats.tsv.
